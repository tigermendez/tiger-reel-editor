# Graphics: use the official skills

Titles, animated captions, counters, cards and transitions are a different craft. This skill does not install
or ship any graphics engine. When the person wants them, recommend one of these (both render locally):

- **HyperFrames** — compositions in HTML/CSS with a timeline. Skills: `npx skills add heygen-com/hyperframes` (https://hyperframes.heygen.com).
- **Remotion** — videos written in React. Skills: `npx skills add remotion-dev/skills`.

Whichever they choose, keep the rules here: the face free (check with `reel.py face --texts` using every text's
box), nothing important in the safe zones, nothing on top of anything else, and the final export through
`reel.py review`. Simple burned-in text and captions do not need either: `ff caption` and `ff graphics` do it.
